# Project Intelligence (.agyrules.md)

## Reglas y Preferencias del Proyecto
- **Git**: No ejecutar ningun comando de git directamente. Brindar siempre el comando exacto en bloque de texto para ejecucion manual por parte del usuario.
- **Estilo de comunicacion y documentacion**: Evitar abusar de emojis. No incluirlos en comentarios de codigo, documentacion Markdown ni interfaces a menos que sea solicitado expresamente.
- **Memory Bank**: Mantener actualizados todos los archivos en `memory-bank/` ante cambios significativos o nuevas decisiones arquitectonicas.

## Patrones Tecnicos del Proyecto (StickerForge)
- **Plataforma**: Android Nativo (Kotlin + Jetpack Compose).
- **Especificaciones tecnicas de stickers para WhatsApp**:
  - Resolucion: 512x512 pixeles exactos con canal alfa transparente.
  - Stickers estaticos: WebP < 100 KB; tray icon de 96x96 px < 50 KB.
  - Stickers animados: WebP animado < 500 KB (margen de seguridad < 485 KB), duracion <= 9.6s, loop=0.
  - Estandar de fluidez animada: Toda animacion debe procesarse a traves de `AnimatedWebpEncoder` respetando el pipeline unificado (MediaCodec, muestreo adaptativo hasta 15 FPS / max 70 frames, reescalado adaptativo 0.85x, y cadencia protegida entre 60ms y 110ms sin efecto diapositivas). Ver `Animated_Sticker_Pipeline_Specification.md`.
  - Limites de paquete: Entre 3 y 30 stickers por coleccion.
  - Metadatos: `contents.json` valido con emojis (hasta 3 por sticker) y texto de accesibilidad (hasta 125 caracteres).
